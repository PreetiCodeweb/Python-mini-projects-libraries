# ⏰ Alarm Clock

A simple and modern Alarm Clock application built using Python and Tkinter.

## Features

- Set alarm using Hours, Minutes, and Seconds
- Live digital clock display
- User-friendly graphical interface
- Alarm notification when the selected time is reached
- Sound alert support using WAV files
- Lightweight and beginner-friendly project
- Built entirely with Python

## Technologies Used

- Python 3
- Tkinter
- Datetime
- Winsound (Windows)
- TTK Widgets


2. Navigate to the project folder

```bash
cd mini-python-projects-libaries/Python-Projects/Alarm-Clock
```

3. Run the program

```bash

```

## How It Works

1. Select the desired alarm time.
2. Click the **Set Alarm** button.
3. The application continuously checks the current system time.
4. When the current time matches the alarm time:
   - The alarm is triggered.
   - A sound is played.
   - A notification message is displayed.
